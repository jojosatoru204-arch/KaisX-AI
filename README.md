# KaisX AI

Công ty AI Agent chạy hoàn toàn trong trình duyệt. Giao diện lấy cảm hứng từ Xkiro.com — tối giản, hiện đại, hiệu suất cao.

## Tính năng
- 🏢 6 agent: CEO, CTO, Dev, QA, CMO, Research
- 🤖 Workflow tự động + ReAct tool-use
- 🔑 3 provider: Pollinations (free), Puter (free), BYOK
- 📱 PWA: cài được lên mobile
- 🎨 Logo độc quyền, dark/light theme

## Deploy GitHub Pages
1. Tạo repo public, upload 7 file.
2. Settings → Pages → Deploy from branch → `main` / root → Save.
3. Live tại `https://<username>.github.io/<repo>/`.
